## 1. 需求与目标

- **需求**：运价查询页筛选栏「国家」右侧新增「目的地」查询条件，对应列表**「目的地」列**（卡片视图 meta 行与表格视图信息列是同一显示口径，不是单独某个数据字段）。
- **目的地列显示口径**（`docs/README.md` 字段字典已定，不可另立）：`FBA仓库 → 城市 → 邮编段（开始邮编 - 结束邮编）→ "—"` 依次兜底。
- **目标**：业务按目的地（仓库码片段 / 国名 / 区域）快速过滤运价；输入即时看到结果变化；命中词在目的地位置可快速定位。

## 2. 数据现状依据（选型论证快照）

> 下列为 **2026-10-30 本地 `index.html` 内嵌数据实测快照**，仅用于论证选型；记录数 / 去重值数随每次并表变化，**不作长期红线**。当前规模在 `query/` 仓库根目录跑 `python3 ../parser/tools/current_numbers.py` 现取（与 `docs/README.md` 命令一致）。

| 指标 | 实测值 `[验证]` | 对选型的含义 |
|---|---|---|
| 运价记录总数 | 10,561 条 | 过滤逻辑本身轻量（9/16 实测 `filter()` 约 0.6ms，瓶颈在 DOM 重建、已有防抖兜底；0.6ms 为历史实测值，非当前红线） |
| 目的地去重值 | **589** 个（仓库写法 583 + 澳洲城市 6） | 枚举型下拉体量过大，不适合平铺 |
| 仓库写法形态 | 标准短码 **239**（41%）；复合 / 自由文本 **344**（59%） | 不是规范枚举，等值匹配会漏值 |
| 多仓组合写法 | **212** 个去重值、**999** 条记录（`/` 或换行连接多仓） | 整串等值选不中组合里的单仓，必须子串 / 包含 |
| 「国家」取值 | 7 种（巴西被屏蔽规则隐藏，线上展示 6 种）；美国 9,817 条为主力 | 国家是小基数等值下拉，与目的地不是一个量级 |
| 美国目的地构成 | 以仓库码 / 区域码 / 自提 / 距离描述为主；含中文地名仅 80 条 | 主力市场抽不出「地名标签」，地名快捷选择只覆盖欧洲小量 |
| 「西班牙」命中 | **24 条 = 定点仓 12 + 泛覆盖线 12**；覆盖 12 个渠道 | 地名检索真实存在（欧洲线），但混有两类语义 |
| 现有高亮机制 | 全站命中词高亮 **0 处**（现有蓝色高亮只用于价格备注收费词） | 目的地高亮需新建，范围可控 |
| 现有关键词框 `#f-q` | 已对子串搜索 `FBA仓库 / 城市` 等多字段 | 新框若不限定字段会与之重复 |

**关键判断 `[推断]`**：

1. 目的地写法不规范、基数大，**枚举下拉（select）不适用**；
2. 「抽国家地名做频次标签」只能服务欧洲线小量记录，主力美国市场仍要靠输入匹配；
3. **子串包含匹配**最贴合现有数据形态，是一期匹配方式的基础。

## 3. 选型过程与否决理由

### 3.1 候选方案结论表

| 候选方案 | 结论 | 核心理由 `[验证]` / `[推断]` |
|---|---|---|
| 原生等值下拉（select 平铺） | **否决** | 589 项平铺、长串换行截断不可读；等值选不中 999 条组合记录；`ABE8` 与 `ABE8直送` 被当成两个值，选一漏一 |
| 方案①：抽国家地名 + 频次统计标签 + 文本兜底 | **部分采纳，不进一期** | 地名标签覆盖独立记录仅约 190 条（1.8%）；频次被泛覆盖串灌水（一条长串含十几国、每国重复计数）；高频快捷标签思路列入二期 |
| 方案②：目的地分三类（国家地区 / 仓库 / 其他）做分类筛选 | **否决为筛选维度；分组思路采纳到二期** | 跨类记录 96 条（同一条既含国名又含仓名）；「其他」桶混入 OA 代码、美西/美中/美东区域、自提、英里半径等异质值；分类依赖 parser 结构化字段，前端无法稳定自分 |
| 纯文本框（无实时反馈、无高亮） | **不足** | 无候选引导；与全局关键词框职责不清；命中位置不突出 |
| **方案③：目的地文本框 + 实时过滤 + 命中高亮（定稿）** | **一期落地** | 复用现有实时过滤管线；限定目的地字段后与关键词框不重叠；高亮补足定位体验；成本低、不引入新依赖 |

### 3.2 一句话理由

数据基数大、写法不规范、检索以「片段输入」为主 → **输入型控件优于枚举型控件**；实时过滤 + 命中高亮补足纯文本框的体验短板。

## 4. 一期产品定义（方案③）

### 4.1 位置与外观

- **位置**：筛选栏「国家」右侧（`#f-country` 之后）。
- **控件**：单行文本输入框（搜索框风格，带一键清空）；placeholder 示例：`仓库码 / 国名 / 区域，如 MEM1、西班牙、美西`。
- **命名纪律**：label 逐字为「目的地」；与表格列名 `TBL_INFO_COLS`、卡片 `<span class="k">` 三处**逐字一致**（沿用 9/19 可收货城市建立的命名唯一闸门要求）。
- **布局约束** `[推断]`：现状第 1 行为下拉组、第 2 行为「邮编查询 + 关键词搜索」并排（见 `docs/README.md` 筛选栏布局段）。产品硬要求是**紧邻「国家」右侧**；宽度与相邻控件协调，具体排布由开发按视觉效果定，不挤坏现有 `auto-fit` 均分布局。

### 4.2 匹配规则（核心，不可偏离）

1. **匹配字段 = 目的地列显示值**（§1 兜底串），**不扩展到渠道名、供应商名等其他字段**——这是与关键词框划界的关键。
2. **匹配方式 = 子串包含**（`includes` 语义），**大小写不敏感**；输入首尾 `trim`；连续空白按单空格处理。
3. **一期不做**：等值匹配、仓库后缀（直送 / 卡派）归一清洗、别名映射（英文 Spain、仓码别名当前数据无支撑，不承诺）。
4. **组合关系**：与其他筛选条件 **AND 叠加**；先选「国家」再输目的地 = 在该国结果内收窄；不做强制联动校验、不报错。
5. **空输入 = 不参与过滤**（等同未设置），不改变现有结果。
6. **计数**：复用顶部「显示 N / 总数」实时更新，**不另做频次统计**；N 即当前筛选口径下的真实命中数。

### 4.3 实时反馈

- 输入停顿后刷新列表（**复用现有 180ms 防抖** `RENDER_DEBOUNCE_MS`，不新增定时器）；连续打字不堆积渲染。
- 表格视图、卡片视图两种模式均生效；卡片滚动加载、分组懒渲染等既有性能机制不受影响。

### 4.4 命中高亮

1. **高亮范围仅限目的地**：卡片「目的地」行 + 表格「目的地」列**可见文本**；表格 `data-full` 悬浮原文不高亮。
2. **安全顺序**：先对原文做 HTML 转义，再把命中片段包裹高亮标签（防注入）；输入清空时高亮一并移除。
3. **样式**：建议暖黄底高亮，与现有价格备注的蓝色收费词高亮区分，避免视觉混淆。
4. 匹配大小写不敏感，但高亮展示**原文写法**（不改变显示文本）。

### 4.5 空结果（0 条）处理

- 复用现有空态组件；文案增加目的地引导：`没有匹配的目的地；可输入仓库码片段（如 MEM）、国名（如西班牙）或区域（如美西），或重置筛选`。
- 空态继续显示当前生效筛选条件数（`activeCount()` 扩展纳入本项后自动计数）。

### 4.6 三个输入框的职责边界（防用户混淆）

| 输入框 | 匹配范围 | 典型用法 |
|---|---|---|
| **目的地框（本期新增）** | **仅目的地列显示值** | 查 MEM1、西班牙、马德里、美西 |
| 关键词框 `#f-q`（现有） | 渠道名 / 可收货城市 / 交货仓库 / 城市 / FBA仓库 / 国家 / 文件 / 来源表名 / 供应商代码 | 找渠道名、混字段模糊搜 |
| 邮编框 `#f-zip`（现有） | 邮编区间判定（含全国统一价口径 B） | 客户邮编算带 / 偏远 |

## 5. 落地约束清单（开发必须满足）

1. 字段仅限目的地显示值，不得并入渠道名 / 供应商名等字段。
2. 子串包含、大小写不敏感、首尾 trim；一期不做等值、不做后缀归一。
3. 高亮仅限目的地可见文本；先转义后包裹；清空输入即移除高亮。
4. 纳入筛选生效计数（`activeCount`）与「重置筛选」清空逻辑；重置后输入框清空、高亮消失。
5. 复用现有防抖渲染管线，不新增独立渲染定时器；过滤性能不得劣化（新增条件为 O(n) 子串比较）。
6. 「目的地」命名在筛选 label、表格列名、卡片标签三处逐字一致。
7. 不改动 `__FBA_DATA__` 数据块本身；本项是纯前端筛选 / 展示逻辑。

## 6. 一期明确不做 → 二期路线

| 一期不做项 | 一期处理 | 二期方向 |
|---|---|---|
| 候选联想 / 下拉建议 | 纯输入框 | 输入即出候选，按形态分组（定点仓码 / 覆盖线路 / 区域） |
| 高频快捷标签层（方案①内核） | 无 | 小集合高频项 chips 点选；按「覆盖渠道数」排序动态生成，不写死清单 |
| 写法归一（去「直送 / 卡派」后缀、全半角统一、别名） | 不做 | 匹配前归一化，降低拼写出空结果概率 |
| 直达仓 / 泛覆盖线语义区分 | 不区分 | 结果行加形态标记（前提是《待市场确认清单》第 8 项业务结论） |
| 结构化目的国字段 | 无 | parser 把长国名串拆成覆盖国家清单（跨端任务，另立文档） |

> 频次口径备注 `[推断]`：二期若上标签层，标签旁数字用**覆盖渠道数**，不用记录条数——记录数会被重量档位数重复放大，造成「供给丰富」误判。
