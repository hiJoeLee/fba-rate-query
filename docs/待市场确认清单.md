# 待市场确认清单

> 用途：集中登记运费计算（feat/计费）中需要市场/业务确认后才能落定的事项。
> 规则：每项状态只有 `待确认` / `已确认`；确认后在"确认结论"列回填，并同步改前端/规则实现。
> 更新：2026-10-03 · 当前全部处于待确认，前端以"提示 + 需单询/待确认"闸门兜底，不阻塞开发。

## 1. 偏远判断口径（美国 / 加拿大 / 墨西哥）

**背景（已查证源表）**

| 渠道 | 源表口径 | 是否有邮编清单 |
|---|---|---|
| 墨西哥海运快线 | "墨西哥外州地址卡派报价"表：邮编前两位 → 州/省 → 单价（元/方）；外州地址（除邮编 00-16、50-57 开头）卡派加收 | **有**（邮编前两位结构化表） |
| 墨西哥海运快线 | 外州卡派加收：8 月表 140 元/箱，9 月表 260 元/箱（**价格有版本差异**） | — |
| 墨西哥海运快线 | 墨西哥城外部分仓库（HMO3/BJX1 等）标注"单询" | 有仓库清单 |
| 美国空派上海飞 | "偏远费 30 元/件后期补收" | 无（事后按账单） |
| 美国海卡（芝加哥/休斯顿/奥克兰/纽约） | "偏远地区收费：亚马逊地址 36 元/件、非亚马逊地址 48 元/件" | 无（未定义哪些邮编算偏远） |
| 美国美森 | "美西邮编 90-92 单边超两米收超长费 180/件"（超长费，非偏远） | 邮编 90-92 明确 |
| 加拿大空运/海运 | "私人地址偏远 +48/件"、"普通偏远 +4/KG" | 无 |

**待市场确认**
1. 美国/加拿大的"偏远"如何判定：市场提供邮编清单 / 或统一按"需单询"流程人工判断 / 或维持事后补收；
2. 墨西哥外州卡派加收以哪个版本为准（8 月 140 vs 9 月 260 元/箱）；
3. 墨西哥邮编前两位表是否可作为结构化判定规则落地（唯一能做自动判定的部分）；
4. "偏远费"与"超长费"（90-92 邮编 180/件）是否合并展示、各自触发条件。

**影响**：邮编输入框当前标注"偏远/超大件邮编判定"名不副实（无判定数据）；61 条规则中 3 条"偏远费"规则 trigger 为空，无法自动触发，只能靠"需单询/待确认"兜底。

**状态**：待确认 | **确认结论**：（回填）

## 2. 货物类型映射词典（名称 → 分类）

**背景**：前端内嵌轻量版词典（`TYPE_HINTS*`，源自供应商价格表分类定义），覆盖常用词；未收录词提示"请咨询业务"。

**待市场确认**：市场按实际咨询积累维护完整映射（常见货物名称 → 普货/带电敏感/一类~四类/墨西哥A/B/C），后端 B 阶段入库、前端运行时拉取。

**影响**：词典覆盖率决定建议准确率；但分类永远由客户选定 + 页面明示"分类由客户确认"，前端不产出权威结论，低覆盖不产生错误报价。

**影响**：决定混装报价的最终口径与前端提示文案是否调整。

**背景**：地址类型下拉（FBA仓/商业/私人/学校）当前已传入计算参数（`address_type`），但 61 条规则中**无任何 trigger 引用该字段**，选择不影响任何费用。源表存在口径但未转成规则：

| 渠道 | 源表口径 |
|---|---|
| 美国海卡（奥克兰/纽约/芝加哥/休斯顿） | 非FBA地址 +1元/KG |
| 美国空派上海飞 | 私人地址加收 30元/件 |

**影响**：当前字段无效果，页面已标注"选填，暂不影响价格"；确认转规则前不阻塞计算。

## 7. 燃油费通用规则口径

**背景**：运营后台已新增"通用规则 · 燃油附加费"（独立于来源表，全局生效），支持两种计费形态（按主运费百分比 / 按计费重单价 元·KG·CBM）与"排除已含油渠道"开关。当前源表备注均为**含油**（"含油报价 / 含油含税全包价"：皓鹏美国空运小货特快、扬程美国空运/小包/加拿大空运等），规则库有 2 条"燃油（含油）"included 标记；**源表没有任何"不含油需加收 X%"的燃油费条款**，故费率与适用渠道无数据来源。

**待市场确认**
1. 是否出现/将出现"不含油"渠道（其报价不含燃油，需叠加燃油费）？
2. 若有：燃油费按主运费百分比还是按计费重单价（KG/CBM）收取？费率/单价多少？
3. 是否随国际油价浮动（如 WTI 阈值联动）？还是固定费率？
4. "排除已含油渠道"的判定口径：以备注含"含油/已含"为准，还是以渠道类型（快递/UPS 派送段）为准？

**影响**：框架已落地（数据结构 `fba_admin_gen_v1.fuel` + 后台维护界面），查询页计费引擎接入时按此结构全局叠加；费率确认前默认停用，不阻塞开发。

**状态**：待确认 | **确认结论**：（回填）
